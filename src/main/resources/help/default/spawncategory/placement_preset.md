A convenient built-in spawn-placement profile.

- **MONSTER**: on ground, darkness, and non-Peaceful difficulty.
- **CREATURE**: on animal-spawnable ground in bright light.
- **AMBIENT**: no location restriction, using normal mob checks.
- **WATER_CREATURE**: in water with water above.
- **NO_RESTRICTIONS**: no location restriction, using normal mob checks.

This field is used only when configuration mode is **PRESET**.
